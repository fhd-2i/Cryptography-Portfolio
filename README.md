# Cryptography Portfolio

A collection of practical applied cryptography projects focused on secure system design, encryption, key management, authentication, integrity, and modern cryptographic primitives.

## Projects

### 01 - Cryptographic Secure File Vault

A hybrid cryptographic file protection system built with Python.

The project implements:

- AES-256-GCM for authenticated file encryption
- X25519 ECDH for key agreement
- HKDF-SHA256 for key derivation
- AES-256-GCM for file-key wrapping
- Ed25519 digital signatures
- SHA-256 integrity verification
- Scrypt-based private-key protection
- Trusted signing-key verification
- Command-line and graphical interfaces
- 48 automated cryptographic and security tests

**Project:** `01-Cryptographic-Secure-File-Vault`
